# ChosenOne（天选之子）点名器软件 — 实现文档

## 概述

ChosenOne 是一款 Windows 桌面点名器软件，中文名"天选之子"。核心功能是滚动抽奖式点名：从人名单中随机抽取一人，营造"天选之子"的仪式感。界面元素简单，人名单以纯文本文件形式存放，打包分发后用户可任意修改名单文件，修改自动同步到软件中。

## 技术栈

- **Tauri v2**（Rust 后端 + Web 前端）
- **前端**：纯 HTML/CSS/JS，无构建工具
- **后端**：Rust，负责文件读写与文件变化监视

## 核心需求（已确认）

1. 滚动抽奖式点名（竖排老虎机样式），固定抽取 1 人
2. 自动跳过已点名者，支持一键重置；已点名状态仅存于会话内存，重启即清空
3. 深色 / 浅色双主题，支持本地图片自定义背景
4. 人名单为纯文本 `names.txt`，位于可执行文件同目录
5. 自动监视文件变化，修改即同步到界面
6. 主题 / 背景设置持久化保存，重启后恢复
7. 界面元素简单；**无音效**
8. 窗口可缩放，默认约 480×720，最小 400×600

## 数据文件格式

### names.txt

- 与应用可执行文件同目录
- 每行一个名字；空行和以 `#` 开头的行忽略；重复名字自动去重
- **编码容错**：优先按 UTF-8 读取，解码失败时回退 GBK（Windows 中文环境常用）
- 文件缺失时自动生成包含示例名字的文件

### settings.json

- 与应用可执行文件同目录
- 结构：
  ```json
  { "theme": "dark", "background": "bg_custom.png" }
  ```
- `theme`：`"dark"` 或 `"light"`
- `background`：背景图片文件名，`null`/空串表示使用默认纯色背景；图片需用户手动放到应用目录

## 后端（Rust）设计

Tauri 命令：

| 命令 | 功能 | 说明 |
|---|---|---|
| `get_names()` | 读取并解析 `names.txt` | 返回名字数组；文件缺失时自动生成示例文件 |
| `watch_names_file()` | 启动监视 | 用 Rust `notify` crate 监视文件变化（写入/重命名/删除），重新解析并通过 Tauri event `names-changed` 推送新名单到前端 |
| `load_settings()` / `save_settings()` | 读写 `settings.json` | 启动时加载，改动时保存 |
| `get_app_dir()` | 返回应用目录路径 | 用于打开目录按钮，定位名单文件和放置背景图 |

文件位置全部相对可执行文件所在目录，打包后与 exe 同级。

### 监视机制

- Rust `notify` crate，监视 `names.txt` 文件本身（含父目录以防重命名/删除重建场景）
- 回调触发后重新读取文件 → 解析 → 通过 Tauri event `names-changed` 推送 `Vec<String>`
- 前端收到事件后刷新界面与可抽名单集合

## 前端设计

### 界面布局（单窗口，默认 480×720，最小 400×600，可缩放）

```
┌─────────────────────────┐
│  天选之子         主题 设置 │  ← 顶栏（主题切换、设置）
│                         │
│        ┌─────────┐      │
│        │   (列表滚动区)   │  ← 老虎机：3 行可见，纵向滚动
│        │   王琦          │
│        │   张伟     ★高亮  │  ← 目标行居中标金色高亮放大
│        │   李娜          │
│        └─────────┘      │
│                         │
│   [ 🎲  抽取天选之子  ]    │  ← 主按钮
│   [  已点名 8/40  重置 ]  │  ← 底部状态栏 + 重置按钮
└─────────────────────────┘
```

### 交互流程

1. 点"抽取"：先在可抽集合中**确定目标人**，然后老虎机 3 行纵向滚动约 1.5 秒（滚动内容混入全部名字含已点名者，营造滚动感）→ 减速停在目标行 → 目标行金色高亮 + 放大动画
2. 抽中者加入"已点名"集合，后续抽取自动从可抽集合排除；目标人始终来自未点名集合
3. "重置"清空已点名集合，全部复活；全部抽完时按钮变灰并提示
4. 顶部可切深/浅主题；设置面板可设置背景图
5. 底部状态栏显示"已点名 x/y"计数（不列出已点名者名单，保持界面简单）

### 抽取逻辑

- 维护两个集合：`allNames`（名单全集）与 `picked`（已点名）
- 抽取目标 = 从 `allNames − picked` 中随机取一；无剩余时提示并禁用
- 滚动动画：requestAnimationFrame 驱动，纵移 Y 偏移 + 每帧换行，1.5 秒内 ease-out 减速到目标行
- 样式细节：3 行可见，前后用透明/半透明边行 + 居中高亮目标行的"窗口"效果

### 双主题

- CSS 变量 `--bg`、`--text`、`--accent`、`--surface` 两套值，切换即换
- 自定义背景图覆盖在底色上，加半透明遮罩保证名字可读

### 设置面板

- 主题切换（深色/浅色单选）
- 背景图输入框：填入图片文件名（图片需先手动放入应用目录）
- "打开应用目录"按钮：调用 `get_app_dir()` 后用 `opener://` 或 Tauri `open` 打开资源管理器
- 背景输入为空 = 默认纯色背景

## 打包方案（已确认）

- **安装器**：Tauri v2 内置 NSIS，配置为**每用户安装**（默认 `%LOCALAPPDATA%\Programs\ChosenOne`，无需管理员权限，安装目录可写），安装时允许自定义目录
- **便携版**：Tauri v2 `portable` 目标产出单文件 exe（解压即用、目录天然可写，适合 U 盘/投影）
- 打包产物**不包含** `names.txt` —— 首次运行时软件自动生成含示例名字的文件
- **图标**：`src-tauri/icons/` 提供默认"金色桂冠 + 骰子"风格图标，用户可自行替换

## 验证方案
