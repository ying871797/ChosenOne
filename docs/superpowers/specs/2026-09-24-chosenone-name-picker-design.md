# ChosenOne（天选之子）点名器软件 — 设计规格

## 概述

ChosenOne 是一款 Windows 桌面点名器软件，中文名"天选之子"。核心功能是滚动抽奖式点名：从人名单中随机抽取一人，营造"天选之子"的仪式感。界面元素简单，人名单以纯文本文件形式存放，打包分发后用户可任意修改名单文件，修改自动同步到软件中。

## 技术栈

- **Tauri v2**（Rust 后端 + Web 前端）
- **前端**：纯 HTML/CSS/JS，无构建工具
- **后端**：Rust，负责文件读写与文件变化监视

## 核心需求

1. 滚动抽奖式点名，固定抽取 1 人
2. 自动跳过已点名者，支持一键重置
3. 深色 / 浅色双主题，支持本地图片自定义背景
4. 人名单为纯文本 `names.txt`，位于可执行文件同目录
5. 自动监视文件变化，修改即同步到界面
6. 主题 / 背景设置持久化保存
7. 界面元素简单

## 数据文件格式

### names.txt

- 与应用可执行文件同目录
- 每行一个名字，UTF-8 编码
- 空行和以 `#` 开头的行忽略
- 重复名字自动去重
- 文件缺失时自动生成包含示例名字的文件

### settings.json

- 与应用可执行文件同目录
- 结构：
  ```json
  { "theme": "dark", "background": "bg_custom.png" }
  ```
- `theme`：`"dark"` 或 `"light"`
- `background`：背景图片文件名，`null` 表示使用默认纯色背景；图片需用户手动放到应用目录

## 后端（Rust）设计

Tauri 命令：

| 命令 | 功能 | 说明 |
|---|---|---|
| `get_names()` | 读取并解析 `names.txt` | 返回名字数组；文件缺失时自动生成示例文件 |
| `watch_names_file()` | 启动监视 | 用 Rust `notify` crate 监视文件变化，通过 Tauri event `names-changed` 推送新名单到前端 |
| `load_settings()` / `save_settings()` | 读写 `settings.json` | 启动时加载，改动时保存 |
| `get_app_dir()` | 返回应用目录路径 | 用于提示用户名单文件位置 |

文件位置全部相对可执行文件所在目录，打包后与 exe 同级。

监视机制：`notify` crate（跨平台），监视 `names.txt` 文件本身的变化（重命名/删除/写入），发生时重新解析并通过 `names-changed` 事件推送。

## 前端设计

### 界面布局（单窗口，约 480×720）

```
┌─────────────────────────┐
│  天选之子         主题 设置 │  ← 顶栏（主题切换、设置）
│                         │
│        （名字区）          │  ← 中间大号名字（滚动时轮换）
│       张伟               │
│                         │
│   [ 🎲  抽取天选之子  ]    │  ← 主按钮
│   [  已点名 8/40  重置 ]   │  ← 底部状态栏 + 重置按钮
└─────────────────────────┘
```

### 交互流程

1. 点"抽取"→ 名字区约 1.5 秒快速轮换（约 20fps 随机名字）→ 减速停留 → 命中高亮（金色描边 + 放大动画）
2. 抽中的人加入"已点名"集合，后续抽取自动排除
3. "重置"恢复全部可抽；全部抽完时按钮变灰并提示
4. 顶部可切深/浅主题；设置面板可设置背景图

### 背景图设置方式

- 设置面板提供输入框，填入图片文件名（如 `bg_custom.png`，图片需先手动放入应用目录）
- 提供"打开应用目录"按钮（调用 `get_app_dir()` 后用系统资源管理器打开），方便用户放置图片
- 背景图输入为空即使用默认纯色背景

### 双主题

- CSS 变量 `--bg`、`--text`、`--accent` 两套值，切换即换
- 自定义背景图覆盖在底色上，加半透明遮罩保证名字可读

## 打包方案

- Tauri v2 的 NSIS 安装包 + 便携式 exe
- 打包产物**不包含** `names.txt` —— 首次运行时软件自动生成含示例名字的文件
- 用户直接用记事本修改 `names.txt` 即可

## 验证

- 软件运行中修改 `names.txt` 并保存 → 界面名字自动更新
- 重命名/删除后重建该文件 → 同样同步
- `verification-before-completion` 技能回归验证
