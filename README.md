# ChosenOne 天选之子

桌面点名器软件：滚动抽奖式随机点名，营造"天选之子"仪式感。

## 使用说明

软件运行后，名单来自可执行文件**同目录**下的两个纯文本文件：

| 文件 | 作用 | 说明 |
|---|---|---|
| `names.txt` | 点名名单 | 每行一个名字；空行与 `#` 开头行忽略；重复自动去重 |
| `excluded.txt` | 排除名单 | 其中的人不会被抽选；文件缺失视为无排除 |

**修改即同步**：软件运行中直接用记事本修改这两个文件并保存，界面会立即同步更新。

**编码**：支持 UTF-8 与 GBK（中文 Windows 旧记事本默认），自动识别。

**界面**：
- 🎲 **抽取天选之子**：老虎机滚动动画，1.5 秒减速停驻并高亮命中者
- 已抽中者自动跳过（会话内存，重启软件即恢复全部）
- 🔄 **重置**：清空已点名，全员重新可抽
- 🌗 顶栏切换深色/浅色主题；⚙️ 设置可指定背景图片（放入应用目录后填文件名）
- 底部显示「已点名 x/y · 已排除 n」

## 开发

```bash
npm install                 # 安装 Tauri CLI
npm run tauri dev           # 开发模式
npm run tauri build         # 打包：NSIS 每用户安装器
npx tauri build --no-bundle # 便携版：产出自包含 exe（target\release\chosenone.exe）
                            # 拷到任意目录运行，名单文件与其同目录
```

## 目录结构

```
src/            前端（纯 HTML/CSS/JS，无构建工具）
src-tauri/      Rust 后端（名单解析、文件监视、设置）
docs/           设计文档与架构决策（ADR）
```
